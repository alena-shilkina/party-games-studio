Infographic reference (optional)
One style reference. Claude reads it and every infographic matches its style, colors & elements.
Style only: the reference goes to the image model as a style guide, and the prompt tells the model to draw the NEXT piece in that same illustrated series — same technique, palette and object world, but its own new icons and arrangements, never a copy or trace of the ones in the reference.
Style + characters: same as above, but the recurring subjects carry over too. If the reference is built around a teddy bear, every sheet keeps that teddy bear instead of getting a rabbit. Claude names the characters concretely when it reads the reference, and each sheet redraws them in its own poses and arrangements.
Style text only: the image is never sent; only Claude's written style contract drives the generation. Weaker match — use it when you have no reference you're comfortable attaching.

Image model

Only applies to GPT Image 2. Low costs a fraction of medium and is fine for photo-style and light-text sheets — but check text-heavy printables (trivia, bingo, rules) before running a whole wave on it. High often exceeds Runware's sync window and fails.
Style library

A row's own reference always wins, so a one-off article with a specific character still overrides the library. Paste any public URL — your WordPress media library works well.
